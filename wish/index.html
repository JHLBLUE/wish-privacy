1. 처리 목적·항목·보유기간

기본 타로 기능은 로그인 없이 이용할 수 있습니다. Google·Apple 계정으로 로그인할 때 인증에 필요한 정보를 처리하고, 회원 등록 시 필수 회원 관리 동의와 선택 기록 동기화 동의를 구분해 받습니다.

구분·목적처리 항목보유기간
로그인 요청 처리·인증 보안계정 식별정보, 이메일, 로그인 제공자, 인증 토큰, IP 주소·사용자 에이전트 등 접속정보인증 요청 및 계정 유지에 필요한 기간. Firebase 인증 로그·백업 기간은 제4항 참조
필수 회원 등록·관리, 계정 기능 제공, 동의 내역 관리계정 식별정보, 이메일, Google·Apple 로그인 방식, 동의 내용·버전·일시·앱 플랫폼·필수 및 선택 동의 여부, 이전 동의 내역. 이용한 기능의 개인 알림·읽음 여부·수신 설정·쿠폰 정보·팔로우·좋아요·댓글회원 탈퇴 또는 동의 철회로 회원 서비스가 종료될 때까지
선택 채팅·사주정보·리딩 기록 동기화계정 식별정보, 채팅·대화 요약·참고 풀이·캐릭터·대화 일시, 사주정보(이름·성별·생년월일·출생시간·양음력·윤달·MBTI), 키워드·스프레드·카드·정역방향·해석 결과·기록 식별정보기록 삭제·회원 탈퇴·동의 철회 중 먼저 발생하는 때까지. 별도 리딩 목록은 최근 50개를 보관하며 채팅·사주정보에는 해당 개수 제한을 적용하지 않습니다.
문의·오류 신고·권리 행사 처리이메일 문의: 발신 이메일, 문의 내용·첨부파일. 앱 1:1 문의: 계정 식별값, 유형·내용·선택한 이미지, 답변·처리 상태·동의 시각. 전화번호와 로그인 토큰은 수집하지 않습니다.앱 문의는 종료 후 30일 또는 회원 탈퇴 시 삭제합니다. 분류 기능 종료 전에 별도 보존 대상으로 처리한 기록은 기존 보존기간이 끝나면 삭제합니다. 이메일 문의는 처리 및 필요한 후속 대응 종료 후 삭제하되 별도 보존 대상은 해당 기준을 따릅니다.

로그인 제공자가 이름·프로필 사진을 전달할 수 있습니다. 앱은 이를 리딩 기록에 사용하지 않으며 Firebase 사용자 프로필의 이름·사진을 제거하도록 처리합니다. Apple의 이메일 가리기를 사용하면 중계 이메일 주소를 전달받을 수 있습니다. Google·Apple 계정 비밀번호를 앱이 직접 수집하지 않습니다.

최소 인증 처리는 개인정보 보호법 제15조제1항제4호에 따른 이용자의 로그인 요청 이행을 근거로 합니다. 회원 관리와 기록 동기화는 각각 안내한 동의에 따릅니다. 문의 처리는 이용자의 요청 이행을 위해 필요한 범위에서 진행합니다. 동의하지 않아도 비회원 기본 기능은 이용할 수 있고, 기록 동기화를 거부해도 회원가입은 가능합니다.

구매 복원을 직접 요청하면 스토어의 구매 토큰 또는 거래 식별자와 앱 계정 식별정보를 구매 확인 처리에 사용할 수 있습니다. 현재 버전에서는 유료 기능 판매를 제공하지 않으며, 구매 내역이 없으면 복원할 권한이 없다고 안내합니다. 결제 카드번호를 앱이 직접 수집하지 않습니다.

AI 점술가 활동 정보

팔로우·좋아요 상태와 댓글은 계정별로 서버에 저장합니다. 팔로우·좋아요는 취소할 수 있고 댓글은 작성자가 삭제할 수 있습니다. 댓글은 다른 로그인 회원에게 공개되며 이메일·계정 식별값은 표시하지 않습니다. 댓글 삭제 시 본문은 제거하고 중복 재등록 방지를 위한 요청 식별 해시·작성 시각은 탈퇴까지 보관합니다. 활동 상태·댓글·호출 제한 정보는 탈퇴 시 삭제하며 실패한 단계는 재처리합니다. Firebase가 활동 정보 저장·조회 업무를 처리하며 아래 처리위탁·국외 이전 안내가 적용됩니다.

오늘의 운세

오늘의 운세는 계정·한국 날짜·사주 또는 타로 종류별로 최초 생성 결과를 보관하여 중복 생성을 막습니다. 해당 질문·참고 풀이·생성 답변은 생성 후 48시간 뒤 삭제 대상이 되며 매시간 순차 삭제합니다. 동기화에 동의한 채팅은 이 임시 저장과 별도로 기록 삭제·탈퇴·동의 철회까지 보관합니다.

2. 기기에 저장되는 정보

로그인하지 않은 리딩 기록, 동기화하지 않은 기록, 오늘의 카드, 카드팩 설정과 사주정보는 기기에 저장됩니다. 기록 동기화에 동의한 경우에만 해당 계정의 채팅·사주정보·리딩 기록을 서버에 보냅니다. 비회원 기록을 계정에 가져오는 경우에는 이용자에게 확인을 받습니다.

고객센터 문의와 답변은 로그인한 계정에 연결하여 서버에 저장합니다. 로그인 후 수집·이용에 동의하고 접수 버튼을 누르면 문의를 서버로 보내며, 같은 계정의 문의내역에서 확인할 수 있습니다. 문의를 기기에 임시저장하지 않습니다. 문의정보는 문의 종료 후 30일 또는 회원 탈퇴 시 삭제합니다. 불필요한 개인정보는 문의에 포함하지 마세요. 이메일 문의는 blue@attenbee.com으로 보낼 수 있으며 이용자가 전송하기 전에는 메일이 발송되지 않습니다. 리딩 기록이나 로그인 토큰은 자동 첨부하지 않습니다. 문의 내용과 이미지에 불필요한 민감정보나 비밀번호를 넣지 마세요.

3. 제3자 제공

운영자는 이용자의 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 법령상 의무가 있는 경우를 제외하고, 별도 동의 없이 안내한 목적을 벗어나 제공하지 않습니다. 서비스 제공을 위한 처리위탁은 다음 항목과 같습니다. 이용자가 선택한 Google·Apple 로그인 서비스 자체의 개인정보 처리는 각 제공자의 방침도 적용됩니다.

4. 처리위탁 및 국외 이전

인증과 선택한 기록 동기화에 Google LLC의 Firebase Authentication·Cloud Firestore를 사용합니다. Firebase Authentication은 미국에서 처리되며, 이 앱의 Firestore 데이터베이스, Cloud Functions 및 문의 첨부 저장소는 서울 리전(asia-northeast3)에 위치합니다.

5. 계정 및 기록 삭제 요청·파기

앱에서 계정 삭제

내정보 → 계정 관리 → 계정 삭제를 선택하세요. 최근 로그인 확인이 필요하면 로그아웃 후 다시 로그인하여 삭제를 진행해 주세요.

앱을 사용할 수 없는 경우

blue@attenbee.com으로 계정 삭제 요청을 보내주세요. ‘Wish 계정 삭제 요청’이라는 제목과 가입 시 사용한 이메일·로그인 방식(Google 또는 Apple)을 알려주세요. 비밀번호는 보내지 마세요. 본인 확인에 필요한 최소 정보만 확인한 뒤 처리 결과를 안내합니다.

탈퇴 요청을 서버에 저장한 뒤 Firebase 회원 계정, 서버의 채팅·사주정보·리딩 기록·오늘의 운세·동의 내역·호출제한 데이터를 삭제합니다. 일부 단계가 실패하면 서버가 자동 재시도하며 앱은 접수와 완료를 구분해 안내합니다. Google·Apple 계정 자체는 삭제되지 않습니다. Firebase 인증 백업·로그의 제거 기간은 제4항과 같습니다.

회원 탈퇴 요청을 서버에 저장한 뒤 계정 정보, 서버 리딩 기록, 동의 내역과 호출제한 데이터를 삭제하며 일부 실패는 자동 재시도합니다. 결제·충전·사용·환불 증빙과 잔액 정산 자료는 회원 서비스 데이터에서 분리하여 거래 종료 후 5년간 보관한 뒤 삭제합니다(전자상거래법 시행령 제6조). 앱 서비스 종료 시점은 탈퇴 요청 시각으로 기록하며 이후 스토어 거래·환불 알림 또는 사용 결과 정산이 발생하면 관련 보존 종료 시점을 갱신합니다. 증빙에는 계정 연결용 해시, 거래 식별값·검증 증빙, 상품·금액·잔액·처리 시각을 포함하며 이메일·이름·리딩·동의 내용은 포함하지 않습니다. 해시 연결값도 보호 대상 정보로 취급하며 거래 확인·환불·분쟁 대응 외 목적으로 사용하지 않습니다. 탈퇴 작업 상태는 완료 후 30일, 결제 알림의 운영 처리 기록은 30일 보관한 뒤 삭제합니다. 보존기간 만료 데이터는 정기 삭제 작업에서 순차 처리합니다. 탈퇴만으로 스토어 구독이 해지되거나 잔액이 자동 환불되지는 않으며 환불 등 기존 권리는 유지됩니다.

계정을 유지하면서 리딩 기록만 삭제하려면 나의 기록 → 기록 모두 삭제를 사용하세요. 동기화 중인 계정에서는 서버 기록 삭제도 요청합니다. 동기화 선택 동의는 내정보 → 설정 → 내 개인정보 동의 내역에서 해제할 수 있으며 서버에 동기화된 기록을 삭제합니다.

기기에만 남은 비회원 기록과 설정은 서버 계정 삭제와 별개입니다. 비회원 기록은 해당 기기의 기록 화면에서 삭제하고, 기기 저장 데이터 전체는 앱 데이터 삭제 또는 앱 삭제로 제거할 수 있습니다. 다른 기기에 남아 있는 미전송 기록은 해당 기기에서도 정리해 주세요.

보유기간이 끝나거나 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자적 정보는 해당 저장소에서 삭제하며, 문의 처리 과정에서 종이 자료가 발생했다면 분쇄 등으로 파기합니다. 법령상 별도 보존이 필요한 경우에는 해당 항목·근거·기간을 구분해 안내하고 다른 목적에 사용하지 않습니다.

6. 이용자 및 법정대리인의 권리

이용자와 적법한 대리인은 개인정보 열람·정정·삭제·처리정지·동의 철회를 요청할 수 있습니다. 아래 문의처로 요청하면 본인 또는 대리인임을 확인한 뒤 관련 법령에 따라 처리합니다. 법령에 따라 요청이 제한되는 경우에는 그 이유를 안내합니다. 동의 철회로 회원 서비스를 종료하더라도 비회원 기능은 이용할 수 있습니다.

7. 안전성 확보 조치

인증 정보를 이용해 본인 계정의 기록에만 접근하도록 제한하고, Firebase 접근 규칙과 암호화된 통신을 사용합니다. 운영자는 개인정보 처리에 필요한 범위로 접근을 제한합니다. 만세력과 타로 기초 해석은 앱의 엔진에서 계산합니다. AI 채팅을 요청하면 질문, 답변에 필요한 이전 대화와 요약, 선택한 캐릭터 정보, 관련 사주·타로 풀이를 Firebase 중계 서버를 통해 Google Gemini API로 전송하여 답변을 생성합니다. 채팅에 포함한 개인정보도 함께 전송될 수 있습니다. API 비밀 키는 중계 서버에서 관리하며 앱에 포함하지 않습니다.

AI 채팅과 알림 정보

AI 채팅은 Google LLC의 Gemini API로 처리됩니다. 일반 AI 요청의 대화 본문을 서버 로그에 남기지 않습니다. 오늘의 운세 중복 생성 방지용 질문·참고 풀이·답변은 48시간 보관하며, 기록 동기화에 동의한 채팅은 삭제·탈퇴·동의 철회까지 별도로 보관합니다. 앱 인증 정보와 로그인 계정 또는 설치 식별값, 접속 IP를 이용해 호출량을 제한하며, 호출 제한용 해시와 횟수는 마지막 요청 24시간 후 자동 삭제 대상이 됩니다. Google은 Gemini API의 악용 방지를 위해 입력·관련 문맥·출력을 55일간 보관한다고 안내합니다. 자세한 내용은 Gemini API 데이터 보관 안내를 확인해 주세요. AI 채팅을 이용하지 않아도 기기에서 계산하는 만세력은 볼 수 있습니다.

로그인 계정의 앱 내 알림, 읽음 상태, 알림 수신 설정, 쿠폰은 서버에 저장하며 탈퇴 처리 시 삭제합니다. 비회원의 알림 설정은 해당 기기에 저장됩니다. 기기 푸시는 알림 설정에서 이용자가 켜고 운영체제의 알림 권한을 허용한 경우에 등록합니다. Firebase에 계정 식별값, 기기 알림 토큰, 플랫폼과 갱신 시각을 저장하며 Google Firebase Cloud Messaging 및 iOS의 Apple Push Notification service를 통해 알림을 전달합니다. 해당 처리는 Firebase 서울 리전에 한정되지 않습니다. 잠금화면에는 사주·타로 풀이나 문의 본문 대신 새 알림이 있다는 일반 안내만 표시합니다. 로그아웃 시 기기 연결을 해제하고 탈퇴 시 서버 연결 정보를 삭제합니다. 갱신되지 않은 기기 정보는 30일 후 자동 삭제 대상이 됩니다. 푸시를 켜지 않아도 앱 내 알림 목록에서 내용을 확인할 수 있습니다.
