1. 처리 목적·항목·보유기간

기본 타로 기능은 로그인 없이 이용할 수 있습니다. Google·Apple 계정으로 로그인할 때 인증에 필요한 정보를 처리하고, 회원 등록 시 필수 회원 관리 동의와 선택 기록 동기화 동의를 구분해 받습니다.

구분·목적처리 항목보유기간
로그인 요청 처리·인증 보안계정 식별정보, 이메일, 로그인 제공자, 인증 토큰, IP 주소·사용자 에이전트 등 접속정보인증 요청 및 계정 유지에 필요한 기간. Firebase 인증 로그·백업 기간은 제4항 참조

문의·오류 신고·권리 행사 처리발신 이메일, 이용자가 보내는 문의 내용·첨부파일, 메일에 포함된 앱 버전·운영체제 버전문의 처리 및 필요한 후속 대응이 끝나면 지체 없이 삭제

로그인 제공자가 이름·프로필 사진을 전달할 수 있습니다. 앱은 이를 리딩 기록에 사용하지 않으며 Firebase 사용자 프로필의 이름·사진을 제거하도록 처리합니다. Apple의 이메일 가리기를 사용하면 중계 이메일 주소를 전달받을 수 있습니다. Google·Apple 계정 비밀번호를 앱이 직접 수집하지 않습니다.

최소 인증 처리는 개인정보 보호법 제15조제1항제4호에 따른 이용자의 로그인 요청 이행을 근거로 합니다. 회원 관리와 기록 동기화는 각각 안내한 동의에 따릅니다. 문의 처리는 이용자의 요청 이행을 위해 필요한 범위에서 진행합니다. 동의하지 않아도 비회원 기본 기능은 이용할 수 있고, 기록 동기화를 거부해도 회원가입은 가능합니다.

구매 복원을 직접 요청하면 스토어의 구매 토큰 또는 거래 식별자와 앱 계정 식별정보를 구매 확인 처리에 사용할 수 있습니다. 현재 버전에서는 유료 기능 판매를 제공하지 않으며, 구매 내역이 없으면 복원할 권한이 없다고 안내합니다. 결제 카드번호를 앱이 직접 수집하지 않습니다.

2. 기기에 저장되는 정보

로그인하지 않은 리딩 기록, 동기화하지 않은 기록, 오늘의 카드, 배경 테마·카드팩 설정, 직접 만든 스프레드는 기기에 저장됩니다. 기록 동기화에 동의한 경우에만 해당 계정의 리딩 기록을 서버에 보냅니다. 비회원 기록을 계정에 가져오는 경우에는 이용자에게 확인을 받습니다.

문의 버튼은 메일 앱을 엽니다. 이용자가 전송하기 전에는 문의 메일이 발송되지 않으며, 리딩 기록이나 로그인 정보가 자동 첨부되지 않습니다. 문의 내용에 불필요한 민감정보나 비밀번호를 넣지 마세요.

3. 제3자 제공

운영자는 이용자의 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 법령상 의무가 있는 경우를 제외하고, 별도 동의 없이 안내한 목적을 벗어나 제공하지 않습니다. 서비스 제공을 위한 처리위탁은 다음 항목과 같습니다. 이용자가 선택한 Google·Apple 로그인 서비스 자체의 개인정보 처리는 각 제공자의 방침도 적용됩니다.

4. 처리위탁 및 국외 이전

인증과 선택한 기록 동기화에 Google LLC의 Firebase Authentication·Cloud Firestore를 사용합니다. Firebase Authentication은 미국에서 처리되며, 이 앱의 Firestore 데이터베이스는 미국 리전에 위치합니다.

5. 계정 및 기록 삭제 요청·파기

앱에서 계정 삭제

설정 → 로그인한 계정 → 계정 삭제를 선택하세요. 최근 로그인 확인이 필요하면 로그아웃 후 다시 로그인하여 삭제를 진행해 주세요.

앱을 사용할 수 없는 경우

blue@attenbee.com으로 계정 삭제 요청을 보내주세요. ‘오늘 한 조각 계정 삭제 요청’이라는 제목과 가입 시 사용한 이메일·로그인 방식(Google 또는 Apple)을 알려주세요. 비밀번호는 보내지 마세요. 본인 확인에 필요한 최소 정보만 확인한 뒤 처리 결과를 안내합니다.

계정을 삭제하면 Firebase 회원 계정, 서버의 리딩 기록과 동의 내역을 삭제합니다. Google·Apple 계정 자체는 삭제되지 않습니다. 앱에서 일부 삭제 단계가 실패하면 완료로 표시하지 않고 재시도를 안내합니다. Firebase 인증 백업·로그의 제거 기간은 제4항과 같습니다.

계정을 유지하면서 리딩 기록만 삭제하려면 나의 기록 → 기록 모두 삭제를 사용하세요. 동기화 중인 계정에서는 서버 기록 삭제도 요청합니다. 동기화 선택 동의 철회는 문의 이메일로 요청할 수 있습니다.

기기에만 남은 비회원 기록과 설정은 서버 계정 삭제와 별개입니다. 비회원 기록은 해당 기기의 기록 화면에서 삭제하고, 기기 저장 데이터 전체는 앱 데이터 삭제 또는 앱 삭제로 제거할 수 있습니다. 다른 기기에 남아 있는 미전송 기록은 해당 기기에서도 정리해 주세요.

보유기간이 끝나거나 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자적 정보는 해당 저장소에서 삭제하며, 문의 처리 과정에서 종이 자료가 발생했다면 분쇄 등으로 파기합니다. 법령상 별도 보존이 필요한 경우에는 해당 항목·근거·기간을 구분해 안내하고 다른 목적에 사용하지 않습니다.

6. 이용자 및 법정대리인의 권리

이용자와 적법한 대리인은 개인정보 열람·정정·삭제·처리정지·동의 철회를 요청할 수 있습니다. 아래 문의처로 요청하면 본인 또는 대리인임을 확인한 뒤 관련 법령에 따라 처리합니다. 법령에 따라 요청이 제한되는 경우에는 그 이유를 안내합니다. 동의 철회로 회원 서비스를 종료하더라도 비회원 기능은 이용할 수 있습니다.

7. 안전성 확보 조치

인증 정보를 이용해 본인 계정의 기록에만 접근하도록 제한하고, Firebase 접근 규칙과 암호화된 통신을 사용합니다. 운영자는 개인정보 처리에 필요한 범위로 접근을 제한합니다. 타로 해석은 카드와 자리 자료를 바탕으로 앱에서 처리하며, 리딩 내용을 외부 생성형 AI 서비스로 전송하는 기능을 제공하지 않습니다.

8. 광고·자동 수집 및 이 페이지

현재 버전의 배너·보상형 광고 기능은 비활성화되어 있습니다. 맞춤형 광고 목적으로 정보를 수집·이용하는 기능을 활성화할 때에는 해당 처리 내용과 필요한 선택 방법을 별도로 안내합니다.

앱은 기기 저장소를 기록과 설정 유지에 사용합니다. 인증 과정에서 발생하는 접속정보는 제1항 및 제4항과 같습니다. 이 개인정보처리방침 페이지에는 별도 분석 스크립트·광고·입력 양식을 두지 않습니다. 페이지는 GitHub Pages에서 제공되며, GitHub는 보안을 위해 방문자의 IP 주소를 기록합니다. 자세한 내용은 GitHub Pages 안내와 GitHub 개인정보처리방침을 참고하세요.
